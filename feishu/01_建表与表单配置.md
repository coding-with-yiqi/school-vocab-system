# 飞书建表：照着做，15 分钟

设计思路和为什么是这几张表，见 [00_数据结构设计.md](00_数据结构设计.md)。
这篇只讲手上要点哪里。

> **一条原则贯穿全文：飞书负责存和翻，算账在本机脚本里做。**
> 别在多维表格里用公式实现关系数据库，会陷进去。

## 一、新建多维表格

飞书 → 云文档 → 新建 → **多维表格**，命名「背单词闯关」。
里面建四张数据表。前两张今晚就要用，后两张可以明天再加。

---

## 二、表 1「提交记录」（必须，今晚就要）

把默认数据表改名为 `提交记录`，字段按下表建。
**字段名必须一字不差**，学生端的预填链接靠名字对上。

| 字段名 | 类型 | 备注 |
|---|---|---|
| 班级 | 文本 | 链接带进来的，学生改不了 |
| 姓名 | 文本 | 学生从名单下拉里选的 |
| 内容包 | 文本 | 如 `RJ-XB1-U3-20261118` |
| 第几次 | 数字 | 同一个包第几次做 |
| 对了 | 数字 | |
| 差一点 | 数字 | 拼错一两个字母、改对了但错因选错 |
| 还不会 | 数字 | |
| 待老师看 | 数字 | 造句题数，系统不判对错 |
| 还不会清单 | 多行文本 | `、` 分隔 |
| 差一点清单 | 多行文本 | `、` 分隔 |
| 造句原文 | 多行文本 | 学生写的句子 |
| 自评 | 单选 | 选项：`会了` `不太稳` `我还不会` `没选` |
| 用时秒 | 数字 | |
| 用时偏短 | 文本 | 值是 `是` 或空；**提示，不是指控** |
| 明细 | 多行文本 | 逐题判定，出问题时查账用 |

**不要建「提交时间」字段。** 飞书自己有创建时间，在视图里「显示字段」打开就行。

> 四个数（对了＋差一点＋还不会＋待老师看）加起来等于题数。
> 对不上就是哪里错了，你当场能看出来。

### 做成表单

1. 左下角「+」→ **表单**，命名「交作业」
2. 把上面 15 个字段全部拖进去
3. 右上角「…」→ 分享 → 填写范围选 **「互联网上获得链接的人可填写」**
4. **关掉「填写需登录验证」** ← 这条最关键，不关学生就得有飞书账号
5. 复制表单链接，形如 `https://<你的飞书域名>/share/base/form/shrcnXXXXXXXX`

这个链接交给 `publish.py --form`。

> ⚠️ **发给学生之前，自己用手机交一次。**
> 用无痕窗口或退出飞书账号打开表单链接，填一行提交，回表里看有没有多出来。
> 这一步没做过就发群里，学生做完交不上去，这件事当场就黄了。

## 三、表 2「学生名单」（必须）

新建数据表 `学生名单`。

| 字段名 | 类型 |
|---|---|
| 姓名 | 文本 |
| 班级 | 单选 |
| 学号 | 文本 |
| 在读 | 复选，默认勾上 |

把班级 Excel 直接粘进来。开学一次，整学期不动。

**它存在的唯一理由是算出「谁没交」** —— 没交的人在提交记录里根本不存在。

导出给脚本用：每个班一个 txt，一行一个名字。

```
王小明
李思远
张嘉怡
```

然后：

```bash
python3 scripts/publish.py pack.json -o 高一3班_U3.html \
        --class 高一3班 --roster 高一3班名单.txt --form "<表单链接>"
```

一个班一个网页。班级写死在页面里，名字从下拉里选 —— 班级零歧义，姓名零错字。

## 四、表 3「内容包」（可选，发布时脚本写）

| 字段名 | 类型 |
|---|---|
| 内容包 | 文本（主键） |
| 册次单元 | 文本，人话，如「必修一 Unit 3」 |
| 题数 | 数字 |
| 发布日期 | 日期 |
| 面向班级 | 多选 |
| 是否复习包 | 复选 |

**「是否复习包」别省。** 复习包的成绩跟首次成绩混在一起算，统计就全废了。

## 五、表 4「错题榜」（可选，收作业时脚本写）

| 字段名 | 类型 |
|---|---|
| 班级 | 文本 |
| 内容包 | 文本 |
| 词或题 | 文本 |
| 类型 | 单选：单词 / 句子 / 改错 |
| 还不会人数 | 数字 |
| 差一点人数 | 数字 |
| 没拿下人数 | 数字 |
| 更新时间 | 日期 |

**为什么要单独一张表：** 「还不会清单」是一个用 `、` 分隔的文本字段，
飞书图表不会把它拆开，所以直接拿提交记录画「易错 TOP」是画不出来的。
聚合成一行一个词，看板一个条形图就搞定。

行数可控：3 个班 × 10 个单元 × 50 词 ≈ 1500 行。
**别做「一个学生一个错词一行」那种展开**，一学期 15000 行起，会顶到上限。

## 六、收作业要用的凭据（只在你自己电脑上）

脚本要读写多维表格，需要一个飞书自建应用。

1. 飞书开放平台（open.feishu.cn） → 创建企业自建应用
2. 权限管理 → 开通 `bitable:app`（多维表格读写）
3. 发布版本，等管理员通过
4. 回到多维表格 → 右上角「…」→ 添加文档应用 → 把这个应用加进去
5. 在你自己的终端里：

```bash
export FEISHU_APP_ID=cli_xxxxxxxx
export FEISHU_APP_SECRET=xxxxxxxx
```

> **凭据只存在你自己电脑的环境变量里。**
> 学生拿到的网页里一个密钥都没有，所以随便发群里。
