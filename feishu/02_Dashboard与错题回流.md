# 看板：谁背好了、谁没背、哪些是易错题

字段和表结构见 [00_数据结构设计.md](00_数据结构设计.md) 和 [01_建表与表单配置.md](01_建表与表单配置.md)。

## 一、四个视图

在「提交记录」上建视图（不是新建表）：

### 「今天交了谁」—— 表格视图
- 筛选：创建时间 = 今天
- 分组：班级
- 排序：还不会 降序
- 用途：晚自习前扫一眼。

### 「要我亲自看的」—— 表格视图
- 筛选：`自评` = 我还不会 **或** `还不会` ≥ 5 **或** `用时偏短` = 是
- 用途：这是你唯一必须逐条读的地方。

> **注意「待老师看」没进这个筛选。** 造句每次都要人判，把它放进来等于每个人都被点一遍，
> 这个视图就废了。造句单独看「造句原文」那一列。

### 「每人最新一次」—— 分组视图
- 分组：姓名 → 内容包，排序：第几次 降序
- 用途：单元结束时看最终搞定没有。

### 「首次成绩」—— 表格视图
- 筛选：`第几次` = 1
- 用途：**这才是真实掌握程度。** 学生可以反复刷到全对，
  只看最新一次会把「刷了五遍终于全对」和「一次就全对」看成同一种人。

在「错题榜」上建一个：按班级分组，没拿下人数降序。明天讲什么，看这一屏。

**学生名单上不建视图。**「谁没交」由脚本算，不在飞书里凑。

## 二、仪表盘

| 图 | 类型 | 数据来自 | 回答 |
|---|---|---|---|
| 今日提交人数 | 指标卡 | 提交记录，筛选今天 | 多少人做了 |
| 各班提交人数 | 条形图 | 提交记录按班级 | 哪个班要催 |
| 首次对题数分布 | 柱状图 | 提交记录，第几次=1 | 班级整体什么水平 |
| 易错 TOP 20 | 条形图 | **错题榜**，按没拿下人数 | 明天讲什么 |
| 自评 vs 还不会数 | 散点图 | 提交记录 | 谁虚、谁其实会但不自信 |

**最后一张图是你最该看的那张。** 自评「会了」但还不会数高的那几个，
是班里最危险的学生 —— 他们自己不知道自己不会。

## 三、错题自动滚进下一次复习

真正省时间的地方：你不用记谁错了什么。

```
这次做完 → 两个清单进表
              ↓
    按词统计全班（还不会记 2 分，差一点记 1 分）
              ↓
        错题池.json
              ↓
   下个背课包 --review 错题池.json
              ↓
    没拿下的排在第一关最前面
```

**路线 A：学生走了飞书表单**（成绩已经在表里）
```bash
python3 scripts/feishu_pull.py --app-token <多维表格token> --table <表ID> --review 错题池.json
```

**路线 B：学生发的结果码**（没走飞书）
```bash
pbpaste | python3 scripts/collect.py -o 成绩.csv --review 错题池.json --roster 高一3班名单.txt
```

然后：
```bash
python3 scripts/build_pack.py 下个单元词表.md -o pack.json --review 错题池.json
```

### collect.py 的输出长这样

```
✓ 成绩.csv　5 条提交，4 个人

  做了不止一次的（第一次 → 最后一次）：
    张嘉怡　9 ↑ 13　共 2 次

  造句要你判的：3 人　张嘉怡、陈默、李思远

  要你亲自看的：
    王小明　用时偏短，可能是点着玩的
    陈默　自评还不会、6 个没拿下

  名单 8 人，交了 4 人。
  没交（4）：赵一诺、周沐、吴星遥、郑听雨

  全班最没拿下的（明天课上先讲这些）：
    4 人　malaria
    3 人　devote
```

**二十秒看完，然后你就知道明天早读干什么。**

## 四、回流规则

简单到可以跟学生讲清楚：

- 这次**还不会**的记 2 分，**差一点**的记 1 分，都进错题池；
- 全班分数越高的，排得越前；
- 下个包的第一关优先放这些词；
- 连着两次都过了的，不再优先。

要更严可以改成间隔复习（1 天 / 3 天 / 7 天后重测）。第一版先别上：
规则越简单，你越信得过它，学生也越容易接受。

## 五、期末：不是一张表，是一个生成动作

期末前你真正想做的，不是看统计，是**给每个学生一份「你这学期一直没拿下的 20 个词」**。
那是一个网页，不是一行记录。

```bash
# 全学期错题池
python3 scripts/feishu_pull.py --app-token <...> --table <...> --review 期末错题池.json

# 全班总攻：期末前集体过一遍
python3 scripts/build_pack.py 期末词表.md -o 期末冲刺.json --review 期末错题池.json
```

别为了期末专门建一张「总结表」，那张表你看一次就再不打开。

## 六、别指望看板替你做的事

- 看板显示的是**文字回忆**的结果，不是口语，也不是成绩。
- 造句永远落在人工判这一栏，系统不替你判对错。
- 「用时偏短」是提示，不是指控。
- 自评和系统结果打架时，那恰恰是最该看的一条。
- 「谁没交」飞书算不了（那是个左连接），脚本算，一秒钟。
